# Task 15 – Product Count Analysis

## 📌 Objective

Count products by category and identify the largest product category using Excel.

## 🛠️ Tools Used

- Microsoft Excel
- COUNTIF
- COUNTIFS
- PivotTable

## 📊 Project Description

This project analyzes product data by category. The main objective is to count the number of products available in each category and identify the category with the highest product count.

## 📁 Dataset Columns

- Product ID
- Product Name
- Category
- Sub-Category

## 🔢 Excel Formula

### COUNTIF

All three categories contain 10 products, so there is no single largest category.
